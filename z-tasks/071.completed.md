# Task 071: VFS Logical Core — Mutation Tests (T-11.2)

## Objective
Add Rust unit tests for `RoseLogicalCore` mutation operations: mkdir (create collage/playlist), rmdir (delete collage/release), rename (rename collage/playlist), unlink (remove track from playlist, delete cover art), and open/write/release for special operations.

## Context
Python has integration tests for VFS mutations (collage CRUD, playlist CRUD, release deletion, cover art write through VFS). The Rust VFS has no tests for any mutation operations. This task covers the write-path dispatch logic.

## Files to Read
- `rose-rs/rose-vfs/src/logical.rs` — Rust implementation
- `rose-vfs/rose_vfs/virtualfs_test.py` — Python tests: `test_virtual_filesystem_collage_actions`, `test_virtual_filesystem_playlist_actions`, `test_virtual_filesystem_delete_release`, `test_virtual_filesystem_release_cover_art_actions`, `test_virtual_filesystem_playlist_cover_art_actions`

## What to Implement

Add tests to `rose-rs/rose-vfs/src/logical.rs`:

### Collage operations:
1. **`test_mkdir_creates_collage`** — mkdir at `/Collages/New Collage`. Assert collage TOML file created on disk.
2. **`test_rmdir_deletes_collage`** — rmdir at `/Collages/{existing}`. Assert collage gone.
3. **`test_rename_collage`** — rename `/Collages/Old` to `/Collages/New`. Assert file renamed on disk.
4. **`test_open_adds_release_to_collage`** — open a release directory under a collage path. Assert the release is added to the collage TOML.

### Playlist operations:
5. **`test_mkdir_creates_playlist`** — mkdir at `/Playlists/New Playlist`. Assert created.
6. **`test_rmdir_deletes_playlist`** — rmdir at `/Playlists/{existing}`. Assert deleted.
7. **`test_rename_playlist`** — rename playlist. Assert renamed on disk.
8. **`test_unlink_removes_track_from_playlist`** — unlink a track file under a playlist path. Assert track removed from TOML.

### Release operations:
9. **`test_rmdir_deletes_release`** — rmdir at `/Releases/{release}`. Assert source directory trashed/deleted.

### Cover art operations:
10. **`test_write_release_cover_art`** — Open a cover art path for writing, write data, release the handle. Assert the cover art file is created in the release directory.

## Tests to Write
10 new test functions.
