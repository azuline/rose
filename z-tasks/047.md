# Task 047: End-to-End Smoke Test (M-15.1)

## Objective
Write a smoke test script that exercises every CLI subcommand of the Rust `rose` binary against a temporary library built from `testdata/`, verifying that all commands exit 0 (or exit with expected non-zero for error cases).

## Context
Rose is a music library manager that has been migrated from Python to Rust. The Rust CLI binary is at `rose-rs/rose-cli/`. This task creates a comprehensive end-to-end test that validates every subcommand works against real audio files before the old Python code is deleted.

## Constraints Relevant to This Task
- The test must use `testdata/` (real audio files: `Test Release 1/`, `Test Release 2/`, `Test Release 3/`, `Tagger/`, `Collage 1/`, `Playlist 1/`).
- Copy `testdata/` into a temp directory so tests don't modify the repo.
- The test must create a valid config TOML pointing `music_source_dir` at the temp directory.
- VFS mount/unmount tests may need to be skipped in CI (FUSE requires privileges). Guard with an env var like `ROSE_TEST_FUSE=1`.
- The `rose` binary must be built first — the test should either build it or assume it exists at a known path.

## Files to Read
- `rose-rs/rose-cli/src/main.rs` (to verify exact subcommand names and argument formats)
- `testdata/` directory structure (to know what release IDs and names are available)
- `testdata/Test Release 2/.rose.ilovecarly.toml` and `testdata/Test Release 3/.rose.ilovenewjeans.toml` (to get release UUIDs)
- `testdata/Collage 1/Rose Gold.toml` and `testdata/Playlist 1/Lala Lisa.toml` (to get collage/playlist names)

## What to Implement

Create `rose-rs/tests/smoke_test.sh` (a bash script):

1. **Setup:**
   - `set -euo pipefail`
   - Create a temp directory, copy `testdata/` into it as the music source.
   - Write a minimal `config.toml` with `music_source_dir` pointing to temp dir.
   - Set `ROSE_CONFIG_PATH` env var (or pass `--config` flag if supported).
   - Build or locate the `rose` binary.

2. **Exercise every command** in order:
   - `rose version`
   - `rose cache update` (must run first to populate the cache)
   - `rose releases print-all` (capture output, extract a release ID)
   - `rose releases print <id>`
   - `rose releases toggle-new <id>`
   - `rose releases toggle-favorite <id>`
   - `rose releases set-rating <id> 8`
   - `rose tracks print-all` (capture a track ID)
   - `rose tracks print <id>`
   - `rose artists print-all`
   - `rose genres print-all`
   - `rose labels print-all`
   - `rose descriptors print-all`
   - `rose collages print-all`
   - `rose collages create "Smoke Test Collage"`
   - `rose collages add-release "Smoke Test Collage" <release_id>`
   - `rose collages print "Smoke Test Collage"`
   - `rose collages rename "Smoke Test Collage" "Renamed Collage"`
   - `rose collages remove-release "Renamed Collage" <release_id>`
   - `rose collages delete "Renamed Collage"`
   - `rose playlists create "Smoke Test Playlist"`
   - `rose playlists add-track "Smoke Test Playlist" <track_id>`
   - `rose playlists print "Smoke Test Playlist"`
   - `rose playlists rename "Smoke Test Playlist" "Renamed Playlist"`
   - `rose playlists remove-track "Renamed Playlist" <track_id>`
   - `rose playlists delete "Renamed Playlist"`
   - `rose rules run --dry-run --yes '<some_simple_rule>'`
   - `rose cache update --force`
   - VFS tests (if `ROSE_TEST_FUSE=1`): mount, ls, unmount.
   - Skip `edit` commands (require `$EDITOR` interaction).

3. **Teardown:** Remove temp directory.

4. **Exit 0** if all commands succeed.

## Tests to Write
The script itself IS the test. It should:
- Print each command before running it (for debugging).
- Fail fast on any non-zero exit.
- Print "SMOKE TEST PASSED" at the end.

## Done When
- `bash rose-rs/tests/smoke_test.sh` exits 0 against the testdata.
- Every non-interactive CLI subcommand is exercised.
- The script is idempotent (uses temp dirs, cleans up).
