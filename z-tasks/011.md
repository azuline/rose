# Task 011: Cache Data Types (M-6.2)

## Objective
Define the Rust data types for all cached entities (Release, Track, Collage, Playlist, etc.) and the `StoredDataFile` sidecar format, plus row deserialization from SQLite views.

## Context
Rose is a music library manager being migrated from Python to Rust. The SQLite cache stores denormalized views of releases, tracks, collages, and playlists. This task defines the Rust structs that represent cached rows and the `StoredDataFile` format used in `.rose.{uuid}.toml` sidecar files.

## Constraints Relevant to This Task
- `.rose.{uuid}.toml` format is frozen: key names `new`, `favorite`, `rating`, `added_at`. Rating uses `-1` for null. `added_at` is ISO8601.
- The UUID is extracted by regex `^\.rose\.([^.]+)\.toml$`.
- SQLite PRAGMAs (WAL, foreign_keys, busy_timeout=15s) on every connection.
- `_unpack` GROUP_CONCAT mismatch: decide silent drop (match Python) or warn log. Recommend: warn via `tracing::warn!` but continue (improves on Python silently dropping).

## What to Implement
All additions go into `rose-rs/rose-core/src/cache.rs`.

1. **`Release` struct** — mirrors Python `Release` dataclass (lines 213–238). Fields: `id`, `source_path` (PathBuf), `cover_image_path` (Option<PathBuf>), `added_at` (String), `datafile_mtime` (String), `releasetitle`, `releasetype`, `releasedate` (Option<RoseDate>), `originaldate`, `compositiondate`, `edition` (Option<String>), `catalognumber`, `new` (bool), `favorite` (bool), `rating` (Option<i32>), `disctotal` (i32), `genres` (Vec<String>), `parent_genres`, `secondary_genres`, `parent_secondary_genres`, `descriptors`, `labels`, `releaseartists` (ArtistMapping), `metahash` (String).

2. **`Track` struct** — fields: `id`, `source_path`, `source_mtime`, `tracktitle`, `tracknumber` (String), `tracktotal` (i32), `discnumber` (String), `duration_seconds` (i32), `trackartists` (ArtistMapping), `metahash`, `release` (Release).

3. **`Collage` struct** — fields: `name` (String), `source_mtime` (String).

4. **`Playlist` struct** — fields: `name`, `source_mtime`, `cover_path` (Option<PathBuf>).

5. **`StoredDataFile`** — fields: `new` (bool), `favorite` (bool), `rating` (Option<i32>), `added_at` (String). Methods: `serialize() -> toml::Value` (rating → -1 for None), `parse(data) -> Result<StoredDataFile>` (rating -1 → None). Default: `new=true, favorite=false, rating=None, added_at=now_iso8601()`.

6. **`STORED_DATA_FILE_REGEX`** — `lazy_static` or `once_cell`: `^\.rose\.([^.]+)\.toml$`.

7. **`GenreEntry`**, **`DescriptorEntry`**, **`LabelEntry`** — each has `name: String, only_new_releases: bool`.

8. **Helper functions** (private):
   - `split_delimited(s: &str) -> Vec<String>` — split on `" ¬ "`.
   - `unpack_artists(config, names_str, roles_str, aliases: bool) -> ArtistMapping` — zip split names/roles, resolve aliases via `config.artist_aliases_parents_map`.
   - `get_all_artist_aliases(config, name) -> Vec<String>` — transitive alias resolution.
   - `get_parent_genres(genres) -> Vec<String>` — look up `TRANSITIVE_PARENT_GENRES`.

9. **Row deserialization**:
   - `cached_release_from_view(config, row, aliases) -> Result<Release>` — reads from `releases_view` columns.
   - `cached_track_from_view(config, row, release, aliases) -> Result<Track>` — reads from `tracks_view` columns.

10. **Log text helpers**:
    - `make_release_logtext(title, releasedate, artists) -> String`
    - `make_track_logtext(title, artists, releasedate, suffix) -> String`

## Tests to Write
1. `StoredDataFile` roundtrip: serialize then parse, verify equality.
2. `StoredDataFile::parse` with `-1` rating → `None`.
3. `StoredDataFile::parse` with valid rating (e.g., `7`) → `Some(7)`.
4. `StoredDataFile::parse` with missing fields uses defaults.
5. `STORED_DATA_FILE_REGEX` matches `.rose.abc-123.toml`, extracts `abc-123`.
6. `STORED_DATA_FILE_REGEX` rejects `rose.abc.toml`, `.rose.toml`.
7. `split_delimited` on empty string → empty vec.
8. `split_delimited` on `"a ¬ b ¬ c"` → `["a", "b", "c"]`.
9. `unpack_artists` with mismatched lengths logs warning and returns partial.
10. `get_parent_genres` returns sorted deduplicated parents.
11. All structs derive `Debug` and `Clone`.
12. `make_release_logtext` and `make_track_logtext` format correctly.
