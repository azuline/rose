# Task 070: VFS Logical Core — Unit Tests (T-11.1)

## Objective
Add Rust unit tests for `RoseLogicalCore` (or its equivalent) covering `getattr`, `readdir`, and the basic FUSE operation dispatch for all view types.

## Context
The Rust VFS has excellent unit tests for path parsing (67 tests), TTLCache, FileHandleManager, and INodeMapper. But `logical.rs` — which implements the core FUSE dispatch logic (getattr, readdir, open, write, unlink, mkdir, rmdir, rename) — has **zero tests**. Python has 13 comprehensive integration tests. This task adds unit-level tests for the read-only operations (getattr, readdir) which are the most critical.

## Files to Read
- `rose-rs/rose-vfs/src/logical.rs` — Rust implementation (no tests yet)
- `rose-rs/rose-vfs/src/virtualfs.rs` — Path parsing + VirtualNameGenerator (has tests)
- `rose-rs/rose-vfs/src/state.rs` — TTLCache, FileHandleManager, INodeMapper (has tests)
- `rose-vfs/rose_vfs/virtualfs_test.py` — Python integration tests for reference

## What to Implement

Add tests to `rose-rs/rose-vfs/src/logical.rs` (or a new `rose-rs/rose-vfs/src/logical_test.rs` if the module structure prefers it). These tests require a seeded cache database and config but NOT a mounted FUSE filesystem:

### readdir tests:
1. **`test_readdir_root`** — Call readdir on root path. Assert it returns all 13 top-level view directories (Releases, Artists, Genres, etc.).

2. **`test_readdir_releases_view`** — Call readdir on `/Releases`. Assert it returns release virtual directory names matching the seeded releases.

3. **`test_readdir_artists_view`** — Call readdir on `/Artists`. Assert it returns artist names from the seeded data.

4. **`test_readdir_release_tracks`** — Call readdir on `/Releases/{release_dir}`. Assert it returns track filenames and cover art.

5. **`test_readdir_collages_view`** — Call readdir on `/Collages`. Assert it returns collage names.

6. **`test_readdir_playlists_view`** — Call readdir on `/Playlists`. Assert it returns playlist names.

### getattr tests:
7. **`test_getattr_root`** — Assert root returns directory attributes.
8. **`test_getattr_release_dir`** — Assert a release directory returns directory attributes.
9. **`test_getattr_track_file`** — Assert a track file returns file attributes with correct size.
10. **`test_getattr_nonexistent`** — Assert a nonexistent path returns ENOENT.

### Whitelist/blacklist integration:
11. **`test_readdir_with_blacklist`** — Configure artist blacklist. Assert the blacklisted artist doesn't appear in `/Artists` readdir.
12. **`test_readdir_with_whitelist`** — Configure artist whitelist. Assert only whitelisted artists appear.
