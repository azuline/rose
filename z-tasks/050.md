# Task 050: Update CI (M-15.4)

## Objective
Update `.github/workflows/build.yaml` to run Rust CI checks (test, clippy, fmt, e2e smoke test, nix build) instead of or alongside the Python CI checks.

## Context
Rose is a music library manager migrated from Python to Rust. The current CI runs Python-only checks: mypy typecheck, pytest, ruff lint, and a Nix build of the Python packages. This task updates CI to validate the Rust codebase.

## Constraints Relevant to This Task
- The CI runs on `ubuntu-latest` via GitHub Actions.
- Nix is installed via `cachix/install-nix-action` and caches via `cachix/cachix-action`.
- FUSE tests may require `sudo apt-get install fuse3 libfuse3-dev` or `fuse libfuse-dev` and `sudo modprobe fuse` — or they may need to be skipped in CI.
- The smoke test script (task 047) is at `rose-rs/tests/smoke_test.sh`.
- Keep Python CI steps temporarily if old Python code hasn't been deleted yet. Use a comment to mark them for removal.

```yaml
name: build
on: push
jobs:
  build:
    runs-on: ubuntu-latest
    env:
      ACTIONS_ALLOW_UNSECURE_COMMANDS: true
    steps:
      - uses: actions/checkout@v3
      - uses: cachix/install-nix-action@v20
      - uses: cachix/cachix-action@v12
        with:
          name: rose
          authToken: "${{ secrets.CACHIX_AUTH_TOKEN }}"
      - name: Build Nix
        run: nix build -j8 .#devShells.x86_64-linux.default
      - name: Typecheck
        run: nix develop --command make typecheck
      - name: Test
        run: nix develop --command make test
      - name: Lint
        run: nix develop --command make lintcheck
      - name: Build
        run: nix build .#all
```

## What to Implement

Edit `.github/workflows/build.yaml`:

1. **Add Rust CI steps** (either within existing job or as a new job):

   ```yaml
   - name: Install system dependencies
     run: sudo apt-get update && sudo apt-get install -y pkg-config libfuse-dev

   - name: Rust format check
     run: nix develop --command cargo fmt --all --check
     working-directory: rose-rs

   - name: Rust clippy
     run: nix develop --command cargo clippy --workspace -- -D warnings
     working-directory: rose-rs

   - name: Rust tests
     run: nix develop --command cargo test --workspace
     working-directory: rose-rs

   - name: E2E smoke test
     run: nix develop --command bash tests/smoke_test.sh
     working-directory: rose-rs

   - name: Nix build (Rust)
     run: nix build .#rose-cli
   ```

2. **Cargo caching** — add a cache step for `rose-rs/target/` and `~/.cargo/registry/`:
   ```yaml
   - uses: actions/cache@v4
     with:
       path: |
         ~/.cargo/registry
         ~/.cargo/git
         rose-rs/target
       key: cargo-${{ runner.os }}-${{ hashFiles('rose-rs/Cargo.lock') }}
       restore-keys: cargo-${{ runner.os }}-
   ```

3. **Conditional FUSE tests** — if FUSE isn't available in CI, set `ROSE_TEST_FUSE=0` so the smoke test skips VFS tests.

5. **Update action versions** while at it: `actions/checkout@v4`, `cachix/install-nix-action@v27` (or latest).

6. **`if: success() || failure()`** on each step so all checks run even if one fails (matching existing pattern).
