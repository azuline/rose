# Task 053: Audiotags — Format Coverage Tests (T-1.1)

## Objective
Add Rust tests for audiotags behaviors that are missing per-format coverage: ID survival for OGG Vorbis/Opus, alt-role tag deletion for OGG Vorbis/Opus, and artist roundtrip via flush for MP3/M4A/OGG Vorbis/OGG Opus.

## Context
The Rust audiotags test suite has 53 tests, but several behaviors are only tested for a subset of the 5 supported formats (FLAC, MP3, M4A, OGG Vorbis, OGG Opus). The Python test suite covers all 5 formats uniformly via parametrized tests. This task fills the format coverage gaps.

## Files to Read
- `rose-rs/rose-core/src/audiotags.rs` — existing Rust implementation + tests (tests start ~line 1548)
- `rose-py/rose/audiotags_test.py` — Python tests for reference (parametrized across formats)

## What to Implement

Add the following tests to `rose-rs/rose-core/src/audiotags.rs`:

1. **`id_survival_ogg_vorbis`** — Write Rose ID and Release ID to an OGG Vorbis file, re-read, assert they match. Mirror existing `id_survival_flac`/`id_survival_mp3`/`id_survival_m4a`.

2. **`id_survival_ogg_opus`** — Same as above for OGG Opus.

3. **`ogg_vorbis_alt_role_tags_deleted`** — Write alt-role tags (remixer, producer, composer, conductor, djmixer) to an OGG Vorbis file, flush with a different artist mapping, verify old tags are cleared. Mirror `flac_alt_role_tags_deleted`.

4. **`ogg_opus_alt_role_tags_deleted`** — Same as above for OGG Opus.

5. **`artist_roundtrip_via_flush_mp3`** — Set a full ArtistMapping (all 7 roles populated), flush to MP3, re-read, assert all roles match. Mirror `artist_roundtrip_via_flush_flac`.

6. **`artist_roundtrip_via_flush_m4a`** — Same for M4A.

7. **`artist_roundtrip_via_flush_ogg_vorbis`** — Same for OGG Vorbis.

8. **`artist_roundtrip_via_flush_ogg_opus`** — Same for OGG Opus.

## Tests to Write
8 new test functions as listed above. Each should copy the appropriate testdata audio file to a temp directory before modifying.

## Done When
- All 8 tests pass with `cargo test -p rose-core audiotags`
- `cargo clippy -p rose-core` is clean
- Commit the changes with a descriptive message
