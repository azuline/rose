# Task 041: Port CLI FS Commands (M-12.10)

## Objective
Wire the filesystem CLI subcommands (`rose fs mount` and `rose fs unmount`) including daemonization with PID file management, SIGTERM handling, and stale PID cleanup.

## Context
Rose is a music library manager being migrated from Python to Rust. The VFS (Virtual Filesystem) exposes the music library as a FUSE filesystem. The `mount` command starts the VFS (optionally as a background daemon), and `unmount` stops it. Daemonization uses `fork()` to detach the process.

## Constraints Relevant to This Task
- `mount` validates path templates expensively before mounting.
- `mount` triggers a background cache update when first starting.
- Without `--foreground`, the process forks: parent writes PID file and exits, child calls `setsid()` and continues.
- **Fix stale PID handling:** Before forking, check if an existing PID file's process is alive. If not, delete the stale PID file and proceed (Python bug: didn't clean up stale files).
- SIGTERM handler for graceful shutdown (unmount the FUSE filesystem).
- Use `nix::unistd::fork()` for daemonization (or `daemonize` crate).

## What to Implement

### Helper: `daemonize(pid_path: Option<&Path>) -> Result<()>`
1. If `pid_path` is Some and the file exists:
   a. Read the PID.
   b. Check if process is alive (`kill(pid, 0)`).
   c. If alive: error "Daemon is already running in process {pid}".
   d. If dead: log debug, delete the stale PID file, and proceed.
   e. If PID file has invalid content: log debug and proceed.
2. Call `fork()`.
3. Child (pid == 0): call `setsid()`, return Ok (child continues).
4. Parent (pid > 0): write child PID to pid_path, call `std::process::exit(0)`.

### SIGTERM Handler
Install a signal handler (via `ctrlc` crate or `signal-hook`) that triggers graceful FUSE unmount on SIGTERM.

### Subcommands under `rose fs`:

#### `rose fs mount [--foreground]`
1. Load config.
2. Validate path templates (`config.validate_path_templates_expensive()`).
3. If not `--foreground`: call `daemonize(None)` (no PID file for VFS — Python doesn't use one for mount).
4. Spawn a background thread/task to run `update_cache(c, false)`.
5. Call `mount_virtualfs(c, debug)` (blocking).
6. Join the cache update thread.

#### `rose fs unmount`
1. Load config.
2. Call `unmount_virtualfs(c)`.
