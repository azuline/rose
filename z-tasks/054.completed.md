# Task 054: Audiotags — Mutation and Edge Case Tests (T-1.2)

## Objective
Add Rust tests for audiotags behaviors involving field mutation before flush, release type normalization on read, tag splitter edge cases, and artist deduplication.

## Context
The Python audiotags tests exercise several behaviors not covered by the Rust suite: modifying fields (artist roles, dates) before flushing and verifying the roundtrip, normalization of invalid release types on read, splitting on `vs.` and ` / ` delimiters, and deduplication of artists across keyword extraction and separate role arguments.

## Files to Read
- `rose-rs/rose-core/src/audiotags.rs` — Rust implementation + tests
- `rose-py/rose/audiotags_test.py` — Python tests (`test_flush`, `test_releasetype_normalization`, `test_split_tag`, `test_parse_artist_string`)

## What to Implement

Add the following tests to `rose-rs/rose-core/src/audiotags.rs`:

1. **`mutate_artist_role_then_flush`** — Read a FLAC file, change `trackartists.djmixer` to a new artist, flush, re-read, verify old djmixer is gone and new one is present. This tests that alt-role tags are properly cleared and new values encoded.

2. **`mutate_date_then_flush`** — Read a FLAC file, change `originaldate` to a new `RoseDate(1990, Some(4), Some(20))`, flush, re-read, verify the date roundtrips correctly.

3. **`releasetype_normalization_on_read`** — Manually write an invalid releasetype string (e.g. "BOGUS") to a FLAC file's tags, then read via `AudioTags::from_file`, assert it normalizes to `"unknown"`.

4. **`releasetype_case_insensitive_on_read`** — Write `"ALBUM"` as releasetype, read back, assert it normalizes to `"album"`.

5. **`tag_splits_on_vs`** — Test `split_tag` with input `"a vs. b"`, assert it produces `["a", "b"]`.

6. **`tag_splits_on_slash`** — Test `split_tag` with input `"a / b"`, assert it produces `["a", "b"]`.

7. **`artist_deduplication_across_sources`** — Call `parse_artist_string` with `"A pres. B"` and a separate `dj=["A"]` argument. Assert that `djmixer` contains only one `"A"` (deduplication across keyword extraction and explicit arg).

8. **`m4a_none_string_tracknumber`** — Set tracknumber to the literal string `"None"` on an M4A file, flush, verify it doesn't error and reads back as a sensible default.
