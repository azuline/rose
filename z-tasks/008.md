# Task 008: Port templates.rs (M-4.1)

## Objective
Port the path template system from Python (Jinja2) to Rust (minijinja), including template compilation, evaluation, custom filters, sample music data, and the `PathTemplateConfig` type with all default templates.

## Context
Rose is a music library manager being migrated from Python to Rust. Path templates control how release directories and track files are named in both the source directory and the virtual filesystem. Templates use a Jinja-like syntax and are user-configurable.

## Constraints Relevant to This Task
- **Breaking change from Jinja2 to minijinja:**
  - `.rjust(2, '0')` is not supported -> implement `{{ discnumber | pad(2) }}` custom filter.
  - `[:10]` slicing is not supported -> implement `{{ added_at | truncate(10) }}` custom filter.
  - Python method calls like `.rjust()` don't work in minijinja.
  - Verify `or` coalescing works for empty strings / custom types.
- Default templates must be updated to use the new filter syntax.

### Custom filters for minijinja
Register these as custom filters on the minijinja `Environment`:

- **`arrayfmt`**: Format `["a", "b", "c"]` as `"a, b & c"`. Single item -> just the item. Empty -> `""`.
- **`artistsarrayfmt`**: Format `Vec<Artist>` — exclude aliases, if <=3 show `"A, B & C"`, if >3 show `"A et al."`.
- **`artistsfmt`**: Format `ArtistMapping` with role decorations:
  - DJ: `"{dj} pres. {main}"`
  - Composer (if no DJ): `"{composer} performed by {main}"`
  - Conductor: `"{main} under {conductor}"`
  - Guest: `"{main} (feat. {guest})"`
  - Producer: `"{main} (prod. {producer})"`
  - Empty -> `"Unknown Artists"`.
  - Accepts an optional `omit` parameter (list of role names to skip).
- **`releasetypefmt`**: Map lowercase release type to display form (`"album"` -> `"Album"`, `"ep"` -> `"EP"`, `"djmix"` -> `"DJ-Mix"`, etc.).
- **`sortorder`**: `"First Last"` -> `"Last, First"`.
- **`lastname`**: `"First Last"` -> `"Last"`.
- **`pad(width)`**: Left-pad with `'0'` to `width` characters. Replaces `.rjust(2, '0')`.
- **`truncate(length)`**: Take first `length` characters. Replaces `[:10]` slicing.

### Default templates (UPDATED for minijinja syntax)
Release default:
```
{{ releaseartists | artistsfmt }} - {% if releasedate %}{{ releasedate.year }}.{% endif %} {{ releasetitle }} {% if releasetype == "single" %}- {{ releasetype | releasetypefmt }}{% endif %} {% if favorite %} [FAVORITE]{% endif %}{% if new %} [NEW]{% endif %}
```

Track default (NOTE: `rjust` replaced with `pad` filter):
```
{% if disctotal > 1 %}{{ discnumber | pad(2) }}-{% endif %}{{ tracknumber | pad(2) }}. {{ tracktitle }} {% if trackartists.guest %}(feat. {{ trackartists.guest | artistsarrayfmt }}){% endif %}
```

### `PathTemplateConfig` struct
Fields for every VFS view: `source`, `releases`, `releases_favorite`, `releases_new`, `releases_added_on`, `releases_released_on`, `artists`, `genres`, `descriptors`, `labels`, `loose_tracks`, `collages`, `playlists`.

`PathTemplateConfig::with_defaults()` — creates config with default templates. Special defaults:
- `releases_added_on.release`: Prefix with `[{{ added_at | truncate(10) }}]` (replaces `{{ added_at[:10] }}`).
- `releases_released_on.release`: Prefix with `[{{ originaldate or releasedate or '0000-00-00' }}]`.
- `collages.release`: Prefix with `{{ position }}.`.
- `playlists`: Standalone track template with position.
