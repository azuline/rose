### Titlecase Decision: Intentional Divergence from Python

Rust's `titlecase` function only capitalizes the first character of the string, leaving the rest unchanged:
- `"some_unknown_type"` → `"Some_unknown_type"`

Python's `str.title()` capitalizes the first letter after every non-alphanumeric character:
- `"some_unknown_type"` → `"Some_Unknown_Type"`

**Decision: Intentionally diverge.** The `titlecase` fallback only applies to release types not in the `RELEASE_TYPE_FORMATTER` map, which covers all known release types (album, single, ep, compilation, anthology, soundtrack, live, remix, djmix, mixtape, other, demo, unknown). The fallback is a safety net for unrecognized values, so the simpler Rust behavior is acceptable and the test documents it explicitly.
