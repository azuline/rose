# Task 067: Rules — FTS Search, Confirmation, Dry Run, and Stored Rules Tests (T-8.3)

## Objective
Add Rust integration tests for FTS-based release/track search, false positive filtering via cached data, dry run behavior, and stored metadata rules execution.

## Context
Python tests cover FTS search for releases (`test_fast_search_for_matching_releases`), cache-based false positive filtering, dry run (no writes), and `execute_stored_metadata_rules`. None have Rust equivalents.

## Files to Read
- `rose-rs/rose-core/src/rules.rs` — Rust implementation + tests
- `rose-py/rose/rules_test.py` — Python tests: `test_fast_search_for_matching_releases`, `test_fast_search_for_matching_releases_invalid_tag`, `test_filter_release_false_positives_with_read_cache`, `test_filter_track_false_positives_with_read_cache`, `test_dry_run`, `test_run_stored_rules`

## What to Implement

Add the following integration tests:

1. **`test_fast_search_for_matching_releases`** — Seed database. Search for releases matching `releasetitle:Release`. Assert correct release IDs returned.

2. **`test_fast_search_releases_invalid_tag`** — Search with a track-only tag (e.g. `tracktitle:X`). Assert `TrackTagNotAllowed` error. Verify `artist:X` is allowed (artist is an alias that includes release-level tags).

3. **`test_filter_release_false_positives_with_cache`** — Get FTS results, then filter using cached Release objects. Assert false positives removed.

4. **`test_filter_track_false_positives_with_cache`** — Same for tracks.

5. **`test_dry_run_does_not_write`** — Execute a rule with `dry_run=true`. Assert the audio file tags are NOT modified.

6. **`test_execute_stored_metadata_rules`** — Configure a stored rule in config. Call `execute_stored_metadata_rules`. Assert the rule was applied.

7. **`test_releasetype_defaults_to_unknown_on_delete`** — Execute a delete action on `releasetype`. Assert it defaults to `"unknown"` (not None).

8. **`test_date_validation_on_replace`** — Execute a replace action on `releasedate` with an invalid date string. Assert an error is returned.
