# Task 059: Collages — Editor Flow Integration Tests (T-4.1)

## Objective
Add Rust tests for the `edit_collage_in_editor` flow, including release removal via editor and the end-to-end editor round-trip.

## Context
Python tests monkeypatch `click.edit` to test `edit_collage_in_editor` end-to-end: reordering releases, removing releases by omitting lines, and handling description mismatches. The Rust tests only exercise the logic components in isolation (manual TOML manipulation, UUID mapping) — the actual `edit_collage_in_editor` function is never invoked.

## Files to Read
- `rose-rs/rose-core/src/collages.rs` — Rust implementation + tests (tests start ~line 453)
- `rose-py/rose/collages_test.py` — Python tests: `test_edit_collages_ordering`, `test_edit_collages_remove_release`

## What to Implement

To make `edit_collage_in_editor` testable, the function needs to accept an editor callback instead of hardcoding a process spawn. Refactor and add tests:

1. **Refactor `edit_collage_in_editor`** (or its Rust equivalent) to accept an `editor_fn: impl FnOnce(&str) -> Option<String>` parameter that takes the current text and returns the edited text (or None to abort). The production code path passes a closure that spawns `$EDITOR`; tests pass a closure that transforms the string.

2. **`test_edit_collage_reorder_via_editor`** — Seed "Rose Gold" collage with 2 releases. Call the editor function with a closure that reverses the lines. Assert the TOML file has releases in reversed order. Assert cache reflects the new order.

3. **`test_edit_collage_remove_via_editor`** — Seed "Rose Gold" collage with 2 releases. Call the editor function with a closure that returns only the first line. Assert only 1 release remains in the TOML and cache.

4. **`test_edit_collage_abort`** — Call the editor function with a closure that returns `None`. Assert the collage is unchanged.

5. **`test_edit_collage_description_mismatch`** — Call the editor function with a closure that returns an unrecognized line. Assert a `DescriptionMismatch` error is returned.

## Tests to Write
4 new test functions + 1 refactor of the editor function signature.
