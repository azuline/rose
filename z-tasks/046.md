# Task 046: Expose Write Operations to Python (M-14.3)

## Objective
Expose write/mutation operations from `rose-core` to Python via PyO3, completing the Python scripting API with tag editing, release/collage/playlist CRUD, and rule execution.

## Context
Rose is a music library manager being migrated from Python to Rust. The PyO3 crate `rose-rs/rose-py/` already exposes `Config` (task 044) and all read operations (task 045). This task adds the remaining write operations so Python scripts have full control over the library.

## Constraints Relevant to This Task
- Same patterns as prior tasks: `#[pyfunction]`, accept `&PyConfig`, convert errors to `PyErr`.
- `AudioTags` needs both read and write exposure (`from_file` and `flush`).
- Rule types (`Matcher`, `Pattern`, `Action`, `Rule`) should be exposed if rule execution is exposed, or the Python API can accept string representations parsed internally.
- Functions that interact with `$EDITOR` (like `edit_release`) may not be practical to expose — document this decision.

## Prior Work
The `rose-py` crate at `rose-rs/rose-py/` has:
- `PyConfig`, `PyRelease`, `PyTrack`, `PyCollage`, `PyPlaylist` wrapper types.
- All `list_*`, `get_*`, `update_cache` functions exposed.

## What to Implement

1. **`PyAudioTags`** (`#[pyclass(name = "AudioTags")]`):
   - `#[classmethod] fn from_file(path: &str) -> PyResult<Self>`
   - `fn flush(&self, config: &PyConfig) -> PyResult<()>`
   - Getters/setters for: `tracktitle`, `releasetitle`, `genres`, `labels`, `releasedate`, `tracknumber`, `discnumber`, `duration_seconds`.
   - Setters for mutable fields so scripts can modify tags then flush.

2. **Release write functions:**
   - `toggle_release_new(config, id)`, `toggle_release_favorite(config, id)`
   - `set_release_rating(config, id, rating)` (rating: Option<i32>)
   - `delete_release(config, id)`, `create_single_release(config, path, loose_track)`
   - `set_release_cover_art(config, id, path)`, `delete_release_cover_art(config, id)`

3. **Collage write functions:**
   - `create_collage`, `rename_collage`, `delete_collage`
   - `add_release_to_collage`, `remove_release_from_collage`

4. **Playlist write functions:**
   - `create_playlist`, `rename_playlist`, `delete_playlist`
   - `add_track_to_playlist`, `remove_track_from_playlist`
   - `set_playlist_cover_art`, `delete_playlist_cover_art`

5. **Rule execution:**
   - `execute_stored_metadata_rules(config, dry_run, yes)` — this is the most useful one for scripting.
   - Optionally: `execute_metadata_rule` if `Rule` can be constructed from Python (may require exposing `Matcher`/`Action` types or accepting a rule string).

6. **Register all new classes/functions** in the `rose` pymodule.
