# Task 072: Watcher — Event Dispatch Integration Tests (T-12.1)

## Objective
Add Rust tests for the watcher's `handle_event` dispatch logic (event type → cache update function call) and verify the full event → cache update pipeline.

## Context
The Rust watcher has 15 tests for event classification, debouncing, and event kind mapping. But `handle_event` — which dispatches classified events to the appropriate cache update function — has no tests. Python has one comprehensive integration test.

## Files to Read
- `rose-rs/rose-cli/src/watcher.rs` — Rust implementation + tests (tests start ~line 379)
- `rose-watch/rose_watch/watcher_test.py` — Python test: `test_watchdog_events`

## What to Implement

Add the following tests to `rose-rs/rose-cli/src/watcher.rs`:

1. **`test_handle_collage_created_event`** — Create a `WatchdogEvent` with type=Created and a collage name. Call `handle_event`. Assert the collage is now in the cache (or that `update_cache_for_collages` was called — may need to verify via DB state).

2. **`test_handle_collage_deleted_event`** — Seed a collage in cache. Create a Deleted event. Call `handle_event`. Assert the collage is evicted from cache.

3. **`test_handle_release_created_event`** — Create a release directory on disk + a Created event. Call `handle_event`. Assert the release is cached.

4. **`test_handle_release_deleted_event`** — Seed a release in cache. Delete its directory. Create a Deleted event. Call `handle_event`. Assert evicted.

5. **`test_handle_playlist_modified_event`** — Modify a playlist TOML. Create a Modified event. Call `handle_event`. Assert cache reflects the modification.

6. **`test_handle_moved_event`** — Rename a release directory. Create a Moved event. Call `handle_event`. Assert old is evicted and new is cached.

## Tests to Write
6 new test functions. These require a Config + seeded cache, so they may need test infrastructure similar to `cache.rs`.

## Done When
- All 6 tests pass with `cargo test -p rose-cli watcher`
- `cargo clippy -p rose-cli` is clean
- Commit the changes with a descriptive message
