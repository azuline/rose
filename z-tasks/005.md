# Task 005: Port audiotags.rs — Reading (M-2.1)

## Objective
Port the audio tag reading layer from Python's mutagen to Rust's lofty, supporting all 5 audio formats with complete field coverage, artist string parsing/formatting, and fallback tag key handling.

## Context
Rose is a music library manager being migrated from Python to Rust. The audiotags module abstracts over 5 audio formats (FLAC, MP3, M4A, OGG Vorbis, OGG Opus) with a single `AudioTags` struct. This is the highest-risk module — incorrect tag reading/writing corrupts the music library.

## Constraints Relevant to This Task
- **Audio tag structure is frozen.** The on-disk tag format (roseid, rosereleaseid, genre encoding with `;`, artist role encoding, `\\PARENTS:\\` delimiter) cannot be changed.
- Dep: `lofty` crate for audio tag I/O.

### Two different `TAG_SPLITTER_REGEX` patterns (Key Behavior #14)
This is critical and easy to miss:
- **Genre/descriptor/label splitting** (`_split_tag`): `r"\\\\| / |; ?| vs\. "` — no spaces around `\\`.
- **Artist splitting** (`parse_artist_string` internal): `r" \\\\ | / |; ?| vs\. "` — WITH spaces around `\\`.

These are two separate regex patterns. The Python code redefines `TAG_SPLITTER_REGEX` at line 550.

### `AudioTags::from_file(path: &Path) -> Result<AudioTags, RoseError>`
Read tags for all 5 formats. Key behaviors:

**Fallback tag keys (Key Behavior #15):**
- MP3 date: try `TDRC`, then `TYER`, then `TDAT`
- MP3 release type: try `TXXX:RELEASETYPE`, then `TXXX:MusicBrainz Album Type`
- MP4 original date: try `----:net.sunsetglow.rose:ORIGINALDATE`, `----:com.apple.iTunes:ORIGINALDATE`, `----:com.apple.iTunes:ORIGINALYEAR`
- Vorbis label: try `label`, `organization`, `recordlabel`

**TIPL/IPLS paired text frames for MP3 (Key Behavior #16):**
- Producer and DJ-mix roles read from ID3 paired text frames (`TIPL`/`IPLS`). These are key-value pairs like `[("producer", "Name")]`.
- Verify `lofty` support for paired frames. If not supported, document the gap and implement a workaround.

**ID3 `TRCK`/`TPOS` combined format (Key Behavior #17):**
- MP3 stores track/disc as `number/total` in one tag. Split on `/` to get both parts.

**`\\PARENTS:\\` delimiter (Key Behavior #3):**
- Genre and secondary genre tags may contain `\\PARENTS:\\` — strip everything after this delimiter on read.

### `parse_artist_string` (Key Behavior #13)
```rust
pub fn parse_artist_string(
    main: Option<&str>,
    remixer: Option<&str>,
    composer: Option<&str>,
    conductor: Option<&str>,
    producer: Option<&str>,
    dj: Option<&str>,
) -> ArtistMapping
```
Bidirectional keyword-delimiter protocol. Parse order matters:
1. Extract `produced by` from main string -> producer list
2. Extract `remixed by` from main string -> remixer list
3. Extract `feat.` from main string -> guest list
4. Extract `pres.` from main string -> dj list (note: dj is LEFT side, main is RIGHT)
5. Extract `performed by` from main string -> composer list (composer is LEFT, main is RIGHT)
6. Extract `under.` from main string -> conductor list

Individual artists within each role are split by the artist splitter regex (WITH spaces around `\\`).

### `format_artist_string` (Key Behavior #13)
```rust
pub fn format_artist_string(mapping: &ArtistMapping) -> String
```
Reverse of parse. Compose order:
`{composer} performed by {dj} pres. {main} under. {conductor} feat. {guest} remixed by {remixer} produced by {producer}`
Only include non-alias artists. Roles joined with `;`.

**MUST roundtrip losslessly:** `format(parse(s)) == s` for well-formed strings.

## Tests to Write
1. **Golden file tests:** For each format, read test audio files and compare all fields against golden JSON.
2. **Artist parse roundtrip:** `format(parse("A feat. B remixed by C produced by D")) == "A feat. B remixed by C produced by D"`.
3. **All 6 delimiters individually:** Test `feat.`, `remixed by`, `produced by`, `pres.`, `performed by`, `under.` each in isolation.
4. **Combined delimiters:** `"Debussy performed by Cleveland Orchestra under. Pierre Boulez"`.
5. **Tag splitter regex difference:** Verify genre splits on `\\` (no spaces) and artists split on ` \\ ` (with spaces).
6. **`\\PARENTS:\\` stripping:** `"Rock;Pop\\\\PARENTS:\\\\Classical"` -> `["Rock", "Pop"]`.
7. **Fallback tag keys:** Test MP3 with `TYER` instead of `TDRC`, Vorbis with `organization` instead of `label`.
8. **ID3 TRCK split:** `"3/12"` -> tracknumber `"3"`, tracktotal `12`.
9. **RoseDate parsing:** year-only, full date, with trailing time, empty, garbage.
10. **Unsupported format:** `.wav` file returns error.
