# Task 025: Port collages.rs — Collage CRUD (M-10.1)

## Objective
Port the collages module from Python (`collages.py`, 169 lines) to Rust in `rose-rs/rose-core/src/collages.rs`. This provides create/rename/delete, add/remove release, and interactive editor support for collages.

## Context
Rose is a music library manager being migrated from Python to Rust. Collages are ordered lists of releases stored as TOML files in `{music_source_dir}/!collages/`. Each entry has a `uuid` and a `description_meta` (human-readable label). The editor integration lets users reorder/remove releases by editing a plain-text list.

## Constraints Relevant to This Task
- **FIX BUG:** Duplicate `description_meta` collision — the Python collage editor uses `description_meta` as the key for UUID lookup, but two releases can have the same description. Add a `[uuid]` discriminator when duplicates exist (matching what playlists already do in Python `playlists.py:160-168`).
- Rename also renames adjacent files with matching stem (e.g., cover art images).
- Use `trash` crate for deletion.
- All modifications use advisory locking via `lock()` / `collage_lock_name()`.
- Collage TOML files live at `{music_source_dir}/!collages/{name}.toml`.

## What to Implement

### 1. `collage_path(c, name) -> PathBuf`
Returns `{music_source_dir}/!collages/{name}.toml`.

### 2. `create_collage(c, name)`
- Create `!collages` directory if needed. Acquire lock. Error if already exists. Touch file. Update cache.

### 3. `delete_collage(c, name)`
- Acquire lock. Error if not exists. Trash via `trash` crate. Evict from cache.

### 4. `rename_collage(c, old_name, new_name)`
- Acquire locks on both names. Error if old doesn't exist or new already exists.
- Rename the TOML file.
- Also rename all adjacent files in `!collages/` that share the old stem (e.g., `{old_name}.jpg` → `{new_name}.jpg`). Skip if destination already exists.
- Update cache for new name, evict old.

### 5. `add_release_to_collage(c, collage_name, release_id)`
- Verify release exists via `get_release_logtext`. Verify collage exists.
- Acquire lock. Read TOML. Check for duplicate (no-op if already present).
- Append `{uuid, description_meta}`. Write TOML. Update cache.

### 6. `remove_release_from_collage(c, collage_name, release_id)`
- Verify release exists. Verify collage exists.
- Acquire lock. Read TOML. Filter out matching UUID. Write TOML. Update cache.

### 7. `edit_collage_in_editor(c, collage_name)` — **WITH BUG FIX**
- Verify collage exists. Acquire lock (60s timeout).
- Read TOML, extract release `description_meta` lines.
- **BUG FIX:** Before presenting to editor, check for duplicate `description_meta` values. If duplicates exist, append ` [{uuid}]` discriminator to each duplicate (matching playlist behavior). Build the UUID lookup mapping from these potentially-discriminated lines.
- Open `$EDITOR` with the text. Handle None return (abort).
- Map each edited line back to UUID via the lookup dict. Error if unknown line.
- Write reordered releases back to TOML. Update cache.
