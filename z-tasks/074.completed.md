# Task 074: CLI Dump — Snapshot Tests (T-13.2)

## Objective
Add Rust tests for the dump module's JSON serialization functions, covering releases, tracks, artists, genres, labels, descriptors, collages, and playlists.

## Context
Python has 18 snapshot tests for dump functions. The Rust `dump.rs` has zero tests. This task adds tests that verify the JSON output structure for each entity type.

## Files to Read
- `rose-rs/rose-cli/src/dump.rs` — Rust dump implementation
- `rose-cli/rose_cli/dump_test.py` — Python snapshot tests for reference
- `rose-cli/rose_cli/dump.py` — Python dump implementation (for field comparison)

## What to Implement

Add tests in a new `#[cfg(test)] mod tests` block in `rose-rs/rose-cli/src/dump.rs` (or a separate test file). These tests require a seeded cache database:

### Release dumps:
1. **`test_dump_release`** — Dump a single release. Assert the JSON contains expected keys: `id`, `source_path`, `releasetitle`, `releasetype`, `releasedate`, `genres`, `labels`, `releaseartists`, `tracks`.
2. **`test_dump_all_releases`** — Dump all releases. Assert the result is a JSON array with the expected count.
3. **`test_dump_releases_with_matcher`** — Dump releases with a matcher filter. Assert only matching releases returned.

### Track dumps:
4. **`test_dump_track`** — Dump a single track. Assert JSON contains `id`, `source_path`, `tracktitle`, `tracknumber`, and release info.
5. **`test_dump_all_tracks`** — Dump all tracks. Assert expected count.

### Entity dumps:
6. **`test_dump_artist`** — Dump a single artist. Assert JSON contains `name` and `releases` partitioned by role (main, guest, remixer, etc.).
7. **`test_dump_all_artists`** — Dump all artists. Assert expected count.
8. **`test_dump_genre`** — Dump a genre with its releases.
9. **`test_dump_all_genres`** — Dump all genres.
10. **`test_dump_label`** — Dump a label with its releases.
11. **`test_dump_all_labels`** — Dump all labels.
12. **`test_dump_descriptor`** — Dump a descriptor with its releases.
13. **`test_dump_all_descriptors`** — Dump all descriptors.

### Collection dumps:
14. **`test_dump_collage`** — Dump a collage with positioned releases.
15. **`test_dump_all_collages`** — Dump all collages.
16. **`test_dump_playlist`** — Dump a playlist with positioned tracks and cover_image_path.
17. **`test_dump_all_playlists`** — Dump all playlists.
