# Task 060: Playlists — Editor Flow and Cover Art Cache Tests (T-5.1)

## Objective
Add Rust tests for the `edit_playlist_in_editor` flow (track removal via editor, abort path) and verify that cover art operations update the cache DB correctly.

## Context
Python tests monkeypatch `click.edit` to test `edit_playlist_in_editor` end-to-end, including removing tracks by omitting lines. Python also verifies that `cover_path` in the cache DB is correctly updated after set/delete/rename operations. The Rust tests only simulate editor behavior manually and only check the filesystem (not the DB) for cover art.

## Files to Read
- `rose-rs/rose-core/src/playlists.rs` — Rust implementation + tests (tests start ~line 588)
- `rose-py/rose/playlists_test.py` — Python tests: `test_edit_playlists_remove_track`, `test_set_playlist_cover_art`, `test_remove_playlist_cover_art`, `test_rename_playlist`

## What to Implement

1. **Refactor `edit_playlist_in_editor`** to accept an `editor_fn` callback (same pattern as Task 059 for collages). If already refactored in Task 059, reuse the same pattern.

2. **`test_edit_playlist_remove_via_editor`** — Seed "Lala Lisa" playlist with 2 tracks. Call editor function with a closure returning only the first line. Assert 1 track remains in TOML and cache.

3. **`test_edit_playlist_abort`** — Call editor function with a closure returning `None`. Assert playlist unchanged.

4. **`test_set_playlist_cover_art_updates_cache`** — Set cover art on a playlist. Query the cache DB's `cover_path` column. Assert it points to the new cover art file.

5. **`test_delete_playlist_cover_art_updates_cache`** — Set cover art, then delete it. Query the cache DB. Assert `cover_path` is NULL.

6. **`test_rename_playlist_updates_cover_path_in_cache`** — Create a playlist with cover art. Rename the playlist. Query cache DB. Assert `cover_path` points to the renamed file.
