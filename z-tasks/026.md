# Task 026: Port playlists.rs — Playlist CRUD (M-10.2)

## Objective
Port the playlists module from Python (`playlists.py`, 236 lines) to Rust in `rose-rs/rose-core/src/playlists.rs`. This provides create/rename/delete, add/remove track, interactive editor, and cover art management for playlists.

## Context
Rose is a music library manager being migrated from Python to Rust. Playlists are ordered lists of tracks stored as TOML files in `{music_source_dir}/!playlists/`. Each entry has a `uuid` and `description_meta`. Playlists already have the `[uuid]` discriminator pattern for duplicate descriptions (unlike collages, which need the bug fix in task 025).

## Constraints Relevant to This Task
- Rename also renames adjacent files with matching stem (e.g., cover art images).
- Cover art for playlists lives adjacent to the TOML file: `{name}.{ext}` in `!playlists/`.
- Use `trash` crate for deletion (not applicable to playlist cover art — use `unlink`/`remove_file`).
- All modifications use advisory locking via `lock()` / `playlist_lock_name()`.
- Playlist TOML files live at `{music_source_dir}/!playlists/{name}.toml`.

## What to Implement

### 1. `playlist_path(c, name) -> PathBuf`
Returns `{music_source_dir}/!playlists/{name}.toml`.

### 2. `create_playlist(c, name)`
- Create `!playlists` directory if needed. Acquire lock. Error if already exists. Touch file. Update cache.

### 3. `delete_playlist(c, name)`
- Acquire lock. Error if not exists. Trash via `trash` crate. Evict from cache.

### 4. `rename_playlist(c, old_name, new_name)`
- Acquire locks on both names. Error if old doesn't exist or new already exists.
- Rename TOML file.
- Also rename all adjacent files in `!playlists/` with matching stem (e.g., cover art). Skip if destination exists.
- Update cache for new name, evict old.

### 5. `add_track_to_playlist(c, playlist_name, track_id)`
- Verify track exists via `get_track()`. Verify playlist exists.
- Acquire lock. Read TOML. Check for duplicate UUID (no-op if present).
- Build description: `"{artistsfmt(trackartists)} - {tracktitle}"`.
- Append `{uuid, description_meta}`. Write TOML. Update cache.

### 6. `remove_track_from_playlist(c, playlist_name, track_id)`
- Verify track exists. Verify playlist exists.
- Acquire lock. Read TOML. Filter out matching UUID. Write. Update cache.

### 7. `edit_playlist_in_editor(c, playlist_name)`
- Verify playlist exists. Acquire lock (60s timeout).
- Read TOML, extract track entries.
- Handle duplicate `description_meta`: count occurrences, append ` [{uuid}]` discriminator to any that appear more than once. Build UUID lookup mapping from these lines.
- Open `$EDITOR`. Handle None return (abort).
- Map edited lines back to UUIDs. Error on unknown lines (`DescriptionMismatchError`).
- Write reordered tracks back to TOML. Update cache.

### 8. `set_playlist_cover_art(c, playlist_name, new_path)`
- Validate extension against `c.valid_art_exts`. Error if unsupported.
- Verify playlist exists.
- Delete existing cover art files (files in `!playlists/` with matching stem and art extension). Use `fs::remove_file` (not trash).
- Copy new file to `{name}.{ext}` in `!playlists/`. Update cache.

### 9. `delete_playlist_cover_art(c, playlist_name)`
- Verify playlist exists.
- Iterate `!playlists/`, remove files with matching stem and art extension. Log found/not found.
- Update cache.
