# Task 040: Port CLI Rules Commands (M-12.9)

## Objective
Wire the rules-related CLI subcommands (`rose rules run` and `rose rules run-stored`) to rose-core's rule execution functions.

## Context
Rose is a music library manager being migrated from Python to Rust. The rules engine finds matching tracks/releases via FTS, applies metadata transformations, and optionally prompts for confirmation. The CLI exposes two commands: ad-hoc rule execution and stored-rule execution from config.

## Constraints Relevant to This Task
- `rose rules run` takes a matcher string, one or more action strings, and optional `--ignore` matchers.
- Actions are variadic (multiple action strings after the matcher).
- `--yes` inverts to `confirm_yes=false` in the rose-core call.
- `--ignore` can appear multiple times (`-i MATCHER1 -i MATCHER2`).
- `--dry-run` shows intended changes without applying.
- If no actions are provided, log "No-Op: No actions passed" and return.

- `execute_metadata_rule(c, rule, dry_run, confirm_yes) -> Result<()>`
- `execute_stored_metadata_rules(c, dry_run, confirm_yes) -> Result<()>`

## What to Implement

### Subcommands under `rose rules`:

#### `rose rules run <MATCHER> [ACTIONS...] [--dry-run] [--yes] [--ignore <MATCHER>]`
Run an ad-hoc metadata rule.

Arguments:
- `MATCHER` (required, positional) — the matcher string (e.g., `"artist:Beatles"`)
- `ACTIONS` (variadic, positional) — one or more action strings (e.g., `"replace:artist:The Beatles"`)
- `--dry-run` / `-d` — display changes without applying
- `--yes` / `-y` — bypass confirmation prompts
- `--ignore` / `-i` — ignore tracks matching this matcher (repeatable)

Implementation:
1. If actions list is empty, log info "No-Op: No actions passed" and return.
2. Parse the rule: `Rule::parse(matcher, &actions, &ignore)`.
3. Call `execute_metadata_rule(c, &rule, dry_run, confirm_yes=!yes)`.

#### `rose rules run-stored [--dry-run] [--yes]`
Run all stored rules from the config file.

Arguments:
- `--dry-run` / `-d`
- `--yes` / `-y`

Implementation:
1. Call `execute_stored_metadata_rules(c, dry_run, confirm_yes=!yes)`.
