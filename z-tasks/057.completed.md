# Task 057: Cache — Alias Resolution, Eviction, and Edge Case Tests (T-2.2)

## Objective
Add Rust tests for transitive artist alias resolution in `get_release`, `artist_exists` with aliases, force-refresh eviction of stale relation rows, empty multi-value tag clearing, and legacy datafile upgrade.

## Context
Python tests cover several cache behaviors that the Rust test suite doesn't: `get_release` returning transitive artist aliases in the ArtistMapping, `artist_exists` working with alias configuration, force-refresh evicting artificially stale rows, clearing all values from a multi-value tag, and upgrading legacy empty datafiles.

## Files to Read
- `rose-rs/rose-core/src/cache.rs` — Rust implementation + tests
- `rose-py/rose/cache_test.py` — Python tests: `test_get_release_applies_artist_aliases`, `test_artist_exists`, `test_update_cache_releases_evicts_relations`, `test_update_cache_releases_to_empty_multi_value_tag`, `test_update_cache_releases_disk_upgrade_old_datafile`

## What to Implement

Add the following tests to `rose-rs/rose-core/src/cache.rs`:

1. **`test_get_release_returns_transitive_aliases`** — Configure artist aliases (A → B → C). Seed a release with artist A. Call `get_release`. Assert the returned `ArtistMapping` includes the alias artists (B and C with `alias=true`).

2. **`test_artist_exists_with_alias`** — Configure alias (A1 aliases to A2). Seed a release with artist A2. Call `artist_exists(c, "A1")`. Assert it returns true (via alias resolution).

3. **`test_force_refresh_evicts_stale_relations`** — Seed a release. Manually INSERT a spurious genre row into the `releases_genres` table. Run `update_cache` with force=true. Assert the spurious genre is gone.

4. **`test_empty_multi_value_tag_clears_db`** — Seed a release with labels `["Label A"]`. Modify the audio file tags to have empty labels. Run cache update. Assert the release has no labels in the DB.

5. **`test_legacy_datafile_upgrade`** — Create a release directory with a `.rose.{uuid}.toml` that is empty (0 bytes). Run cache update. Assert the datafile is now populated with default values (`new = true`, `favorite = false`, etc.) on disk.
