# Task 037: Port CLI Collage Commands (M-12.6)

## Objective
Wire all collage-related CLI subcommands to rose-core functions.

## Context
Rose is a music library manager being migrated from Python to Rust. Collage commands let users create, rename, delete, and manage release membership in collages, plus print them as JSON. Collages are identified by name (not UUID). Release arguments within collage commands use the same UUID/path resolution as release commands.

## Constraints Relevant to This Task
- Collage names are plain strings passed directly to rose-core functions.
- `add-release` and `remove-release` take a release argument (UUID or path) — reuse `parse_release_argument` from task 035.
- Python has dead code `parse_collage_argument` / `parse_playlist_argument` (lines 730–753) — do NOT port these.

## What to Implement

### Subcommands (all under `rose collages`):

#### `rose collages create <NAME>`
Create a new collage. Calls `create_collage(c, name)`.

#### `rose collages rename <OLD_NAME> <NEW_NAME>`
Rename a collage. Calls `rename_collage(c, old_name, new_name)`.

#### `rose collages delete <COLLAGE>`
Delete a collage. Calls `delete_collage(c, name)`.

#### `rose collages add-release <COLLAGE> <RELEASE>`
Add a release to a collage. Resolve release via `parse_release_argument`. Calls `add_release_to_collage(c, collage, release_id)`.

#### `rose collages remove-release <COLLAGE> <RELEASE>`
Remove a release from a collage. Resolve release via `parse_release_argument`. Calls `remove_release_from_collage(c, collage, release_id)`.

#### `rose collages edit <COLLAGE>`
Open collage in $EDITOR for reorder/removal. Calls `edit_collage_in_editor(c, name)`.

#### `rose collages print <COLLAGE>`
Print a collage as JSON. Calls `dump_collage(c, name)`.

#### `rose collages print-all`
Print all collages as JSON. Calls `dump_all_collages(c)`.
