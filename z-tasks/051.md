# Task 051: Delete Old Python Code (M-15.5)

## Objective
Remove all old Python source code, test infrastructure, and build configuration that has been replaced by the Rust implementation, while preserving testdata, documentation, scripts, and planning files.

## Context
Rose is a music library manager that has been fully migrated from Python to Rust. The Rust implementation in `rose-rs/` replaces the Python packages. The old Python code is no longer needed and should be deleted to avoid confusion.

## Constraints Relevant to This Task
- **DELETE** these directories/files (Python packages and infrastructure):
  - `rose-py/` — old Python core library (NOT the new `rose-rs/rose-py/` PyO3 crate!)
  - `rose-cli/` — old Python CLI
  - `rose-vfs/` — old Python VFS
  - `rose-watch/` — old Python watcher
  - `conftest.py` — Python test fixtures
  - `pyproject.toml` — Python project config
  - Old Python Makefile targets (or the entire `Makefile` if all targets are Python-specific)

- **KEEP** these directories/files:
  - `rose-rs/` — the Rust implementation (obviously)
  - `testdata/` — test audio files used by Rust tests
  - `docs/` — documentation (updated in task 052)
  - `scripts/` — utility scripts (e.g., `scripts/rym-genres/`)
  - `z-thinking/` — planning/migration documents
  - `z-tasks/` — task files
  - `.github/` — CI configuration
  - `flake.nix` — Nix build (updated in task 049)
  - `README.md` — documentation
  - `.gitignore`, `LICENSE`, etc.

- **CAUTION:** `rose-py/` (Python) vs `rose-rs/rose-py/` (Rust PyO3) — these are DIFFERENT directories. Only delete the Python one at the repo root.

## Prior Work
- All Rust code is complete and tested in `rose-rs/`.
- CI has been updated to run Rust checks (task 050).
- Nix build has been updated (task 049).
- The old Python code should NOT be needed by anything at this point.

## Files to Read
- Root directory listing (to identify all files/dirs to evaluate)
- `Makefile` (to see which targets reference Python tools)
- `pyproject.toml` (to confirm it's Python-only config)
- `conftest.py` (to confirm it's Python test infrastructure)
- `flake.nix` (to check for remaining Python package references that need cleanup)
- `.gitignore` (to check for Python-specific entries that can be cleaned up)

## What to Implement

1. **Delete Python packages:**
   ```
   rm -rf rose-py/
   rm -rf rose-cli/
   rm -rf rose-vfs/
   rm -rf rose-watch/
   ```

2. **Delete Python infrastructure:**
   ```
   rm conftest.py
   rm pyproject.toml
   ```

3. **Update or delete `Makefile`:**
   - If all targets are Python-specific (mypy, pytest, ruff), delete it.
   - Or replace with Rust-equivalent targets:
     ```makefile
     check: fmt clippy test

     fmt:
     	cargo fmt --all --check
     
     clippy:
     	cargo clippy --workspace -- -D warnings
     
     test:
     	cargo test --workspace
     
     .PHONY: check fmt clippy test
     ```

4. **Clean up `flake.nix`:**
   - Remove Python package definitions (`rose-py`, `rose-watch`, `rose-vfs`, `rose-cli` Python builds).
   - Remove `uuid6` and other Python dependency definitions that are no longer needed.
   - Remove Python-specific dev shell entries (mypy, pytest, ruff, pyright, etc.) unless they're still useful.
   - Keep the Rust dev shell and Rust package builds.

5. **Clean up `.gitignore`:**
   - Remove Python-specific entries (`__pycache__/`, `*.pyc`, `.mypy_cache/`, etc.) if present.
   - Keep Rust entries (`rose-rs/target/`).

6. **Verify nothing is broken:**
   - `nix develop` still works.
   - `nix build` still works.
   - `cargo build` / `cargo test` in `rose-rs/` still works.

## Tests to Write
No new tests. Run existing Rust tests to verify nothing was accidentally deleted:

- Verify `testdata/` is intact.
