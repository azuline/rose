# Task 023: Port releases.rs — Release CRUD (M-9.1)

## Objective
Port the releases module from Python (`releases.py`, 641 lines) to Rust in `rose-rs/rose-core/src/releases.rs`. This is the most complex CRUD module, containing the stateful `edit_release` protocol with TOML null hacks, per-track dirty checking, and resume-on-failure.

## Context
Rose is a music library manager being migrated from Python to Rust. The releases module provides all release-level operations: toggling new/favorite, setting ratings, cover art management, the full interactive metadata editor, single release creation, and rule-based filtering/actions.

## Constraints Relevant to This Task
- `edit_release` is a stateful protocol with TOML null encoding hacks: `-1` for null rating, `""` for null dates/edition/catalognumber (TOML has no null type).
- Per-track per-field dirty checking — only dirty tracks are flushed to disk.
- Resume-on-failure: saves edited TOML to `failed-release-edit.{uuid}.toml` in cache dir, `--resume` reloads it.
- `create_single_release` with `--loose-track` flag sets `releasetype = "loosetrack"`.
- Use `trash` crate for deletion (not permanent delete).
- All `.rose.{uuid}.toml` modifications use advisory locking via `lock()`.

## What to Implement

### 1. Simple state operations
- `delete_release(c, release_id)` — trash via `trash` crate, then evict cache and update collages/playlists.
- `toggle_release_new(c, release_id)` — find `.rose.{uuid}.toml`, toggle `new`, flush, update cache.
- `toggle_release_favorite(c, release_id)` — same pattern for `favorite`.
- `set_release_rating(c, release_id, rating: Option<u8>)` — validate 1-100, write or remove `rating` key.

### 2. Cover art operations
- `set_release_cover_art(c, release_id, new_path)` — validate extension against `c.valid_art_exts`, trash existing cover arts, copy new file as `cover.{ext}`.
- `delete_release_cover_art(c, release_id)` — trash all files matching `c.valid_cover_arts`.

### 3. Intermediary metadata types
- `MetadataArtist { name: String, role: String }` with `from_mapping()` and `to_mapping()` conversions.
- `MetadataTrack { discnumber, tracknumber, title, artists: Vec<MetadataArtist> }`.
- `MetadataRelease` — all release fields plus `tracks: HashMap<String, MetadataTrack>`.
  - `from_cache(release, tracks)` — construct from cache types.
  - `serialize() -> String` — TOML with null hacks: rating `-1`, dates/edition/catalognumber `""`.
  - `from_toml(toml: &str) -> Result<Self>` — parse back, reversing null hacks.

### 4. `edit_release(c, release_id, resume_file: Option<Path>)`
- Trigger `update_cache_for_releases` to ensure fresh data. Reload release.
- Acquire lock. Build `MetadataRelease` from cache (or load resume file).
- Open `$EDITOR` (via `std::process::Command` calling `$EDITOR`). Handle non-zero exit and unchanged file.
- Parse edited TOML via `MetadataRelease::from_toml()`.
- Per-track per-field dirty checking for 15+ fields (tracknumber, discnumber, title, trackartists, releasetitle, releasetype, releasedate, originaldate, compositiondate, edition, catalognumber, genres, secondary_genres, descriptors, labels, releaseartists). Only flush dirty tracks.
- After tag writes, apply new/favorite/rating changes via toggle/set functions.
- On ANY error: save edited TOML to `{cache_dir}/failed-release-edit.{uuid}.toml`, raise error with resume instructions.
- On success: delete resume file if it was used.

### 5. `create_single_release(c, track_path, releasetype: "single"|"loosetrack")`
- Read track tags. Compute dirname: `"{artists} - {year}. {title}"` with collision avoidance.
- Create directory, copy track as `01. {title}{ext}`, copy cover art if present.
- Clear Rose IDs, set releasetitle/type/artists/tracknumber/discnumber. Flush.
- Update cache (with `rename_source_files=false`). Toggle new to false.

### 6. Rule integration
- `find_releases_matching_rule(c, matcher, include_loose_tracks)` — optimize strict lookups via `filter_releases()`, fallback to FTS + false positive filtering.
- `run_actions_on_release(c, release_id, actions, dry_run, confirm_yes)` — load tracks, read audio tags, delegate to `execute_metadata_actions`.
