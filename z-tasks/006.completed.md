# Task 006: Port audiotags.rs — Writing (M-2.2)

## Objective
Extend the `AudioTags` struct with the write path (`flush()`) and ID assignment (`maybe_set_ids()`), supporting all 5 audio formats with correct genre encoding, artist formatting, and format-specific quirks.

## Context
Rose is a music library manager being migrated from Python to Rust. The write path must produce tags identical to what the Python implementation writes. Incorrect writes corrupt the music library.

## Constraints Relevant to This Task
- **Audio tag structure is frozen.** Write output must match Python's format exactly.
- Write path uses only the primary tag key (no fallback keys on write).
- MP3 `TRCK` writes tracknumber only (no total) — tracktotal is lost. This is existing behavior to reproduce.
- MP3 TIPL/IPLS frames are **deleted** on write; producer/DJ info is folded into the main artist string via `format_artist_string`.

## What to Implement

### 1. `AudioTags::flush(&mut self, write_parent_genres: bool) -> Result<(), RoseError>`
Write all fields back to the audio file on disk. Format-specific behavior:

**MP3 (ID3):**
- Standard tags: `TIT2`, `TDRC`, `TDOR`, `TALB`, `TCON`, `TPUB`, `TRCK` (tracknumber only, no total), `TPOS` (discnumber only).
- TXXX tags: `ROSEID`, `ROSERELEASEID`, `COMPOSITIONDATE`, `SECONDARYGENRE`, `DESCRIPTOR`, `CATALOGNUMBER`, `EDITION`, `RELEASETYPE`.
- When writing TXXX tags, preserve other TXXX tags with different descriptions (don't clobber).
- Artist tags: `TPE2` (release artists), `TPE1` (track artists) — use `format_artist_string`.
- **Delete** alt-role tags: `TPE4`, `TCOM`, `TPE3`, `TIPL`, `IPLS` — all roles are folded into the main artist string.

**MP4:**
- Standard atoms: `\xa9nam`, `\xa9day`, `\xa9alb`, `\xa9gen`, `aART`, `\xa9ART`.
- Custom atoms: `----:net.sunsetglow.rose:*` and `----:com.apple.iTunes:*` — written as bytes.
- Track/disc numbers: Write as tuple `(number, prev_total)` — preserve the previous total value from the file.
- **Delete** alt-role atoms: `----:com.apple.iTunes:REMIXER/PRODUCER/CONDUCTOR/DJMIXER`, `\xa9wrt`.

**FLAC/OGG Vorbis/OGG Opus (Vorbis Comments):**
- All tags as simple key=value strings.
- **Delete** alt-role tags: `remixer`, `producer`, `composer`, `conductor`, `djmixer`.

**Genre encoding with `\\PARENTS:\\` (Key Behavior #3):**
When `write_parent_genres` is true:
- Compute parent genres using `GENRE_HIERARCHY` (from `genre_hierarchy.rs`).
- If there are parent genres not already in the user's list, append `\\PARENTS\\` followed by sorted parent genres joined with `;`.
- Example: `"Rock;Pop\\\\PARENTS:\\\\Classical;Jazz"`.

**Release type validation:** Validate that `releasetype` is one of the supported types. Error if not.

### 2. `pub fn maybe_set_ids(tags: &mut AudioTags) -> bool`
If `tags.id` or `tags.release_id` is `None`, generate a new UUID v7 and set it. Return `true` if any IDs were set (caller should flush).

Add `uuid` crate dependency if not present.

### Design Decisions

**Critical lofty 0.22 quirk — `Tag::push()` silently drops `ItemKey::Unknown` items:**
The initial implementation of `flush_vorbis` used the generic `lofty::tag::Tag` struct with
`ItemKey::Unknown("TITLE")`, `ItemKey::Unknown("ROSEID")`, etc. This silently wrote zero
tags because `Tag::push()` calls `item.re_map(tag_type)` which calls
`item_key.map_key(tag_type, false)` — the `false` means `allow_unknown=false`, so all
`ItemKey::Unknown` variants are rejected. The tag appeared to save successfully but the
file had no VorbisComments metadata block afterward.

**Fix:** Replaced the generic `Tag` approach with the native `lofty::ogg::VorbisComments`
struct, which stores items as simple `(String, String)` key-value pairs. Its `insert()`
method writes directly and its `save_to_path()` correctly produces VorbisComments metadata.
The vendor string from the original file is preserved.

**Format-specific write implementations:**
- `flush_mp3`: Uses `lofty::id3::v2::Id3v2Tag` directly. Builds a fresh tag, preserves
  unmanaged TXXX frames from the existing file, writes standard frames (`TIT2`, `TDRC`,
  etc.) and TXXX frames (`ROSEID`, etc.). Alt-role frames (`TPE4`, `TCOM`, `TPE3`,
  `TIPL`, `IPLS`) are deleted by omission (not added to the new tag).
- `flush_mp4`: Uses `lofty::mp4::Ilst` directly. Preserves previous track/disc totals
  from the existing file. Alt-role atoms are deleted by omission.
- `flush_vorbis`: Uses `lofty::ogg::VorbisComments` directly (NOT the generic `Tag`).
  Works for FLAC, Ogg Vorbis, and Ogg Opus. Alt-role tags deleted by omission.
