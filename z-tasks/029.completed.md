# Task 029: VFS RoseLogicalCore — Domain Logic (M-11.3)

## Objective
Port the `RoseLogicalCore` class from Python to Rust in the `rose-vfs` crate. This is the domain logic layer of the VFS that translates virtual filesystem operations (readdir, getattr, open, mkdir, rmdir, rename, unlink) into `rose-core` library calls.

## Context
Rose is a music library manager being migrated from Python to Rust. The `RoseLogicalCore` sits between the low-level FUSE layer (inodes, file handles) and the `rose-core` library (releases, tracks, collages, playlists). It receives parsed `VirtualPath` objects and returns file attributes or performs mutations. It uses `filter_releases`/`filter_tracks` from `rose-core` for view-specific queries.

## Constraints Relevant to This Task
- Date-bucketing for "Added On" / "Released On" views: group releases by date bucket (these are release dirs whose names start with a date prefix).
- `CanShower` whitelist/blacklist determines which artists/genres/descriptors/labels appear.
- `hide_*_with_only_new_releases` config options suppress entries from genre/descriptor/label views.
- `ALL_TRACKS` is a special virtual directory that flattens all tracks across releases into a single listing.
- On `getattr` cache miss for a release/track, trigger a `readdir` on the parent to populate the name generator, then retry.

## What to Implement

### 1. `RoseLogicalCore` struct
Holds references to: `Config`, `FileHandleManager`, `Sanitizer`, `VirtualNameGenerator`, `CanShower`, and the shared state maps (file_creation_special_ops, update_release_on_fh_close).

### 2. `stat(mode, realpath) -> EntryAttrs`
- Dir: `S_IFDIR | 0o755`, nlink=4, uid/gid from process.
- File: `S_IFREG | 0o644`, same.
- If realpath provided, stat the real file for size/times. Suppress FileNotFoundError.

### 3. `getattr(p: &VirtualPath) -> Result<EntryAttrs>`
Dispatch by view type with cascading checks:
- **Playlists**: verify playlist exists, handle cover art and tracks.
- **Collages**: verify collage exists, handle ALL_TRACKS, releases, files.
- **Labels/Descriptors/Genres/Artists**: unsanitize name, verify exists, check CanShower, handle ALL_TRACKS, releases, files.
- **Releases/New/Favorites/Added On/Released On**: handle ALL_TRACKS, delegate to `_getattr_release`.
- **Root/view level**: return dir stat.

### 4. `_getattr_release(p: &VirtualPath) -> Result<EntryAttrs>`
Common logic for release getattr:
- Lookup release via VirtualNameGenerator. On miss, readdir parent and retry.
- If no file → dir stat. If cover art → file stat. If `.rose.{uuid}.toml` → file stat.
- Otherwise → lookup track, verify it belongs to release, return file stat.

### 5. `readdir(p: &VirtualPath) -> Iterator<(String, EntryAttrs)>`
Major dispatch:
- **Root**: yield all 12 numbered view directories.
- **ALL_TRACKS** (in artist/genre/descriptor/label/releases/new/favorites/loose tracks): build matcher, call `find_tracks_matching_rule` or `list_tracks`, yield via `list_track_paths`.
- **ALL_TRACKS in collage**: get collage releases, get tracks of releases, yield via `list_track_paths`.
- **Release dir**: lookup release, get tracks, yield tracks + cover art + `.rose.{uuid}.toml`.
- **Artist/Genre/Descriptor/Label/Releases/New/Favorites level**: build matcher, call `find_releases_matching_rule` or `list_releases`, yield ALL_TRACKS + release dirs via `list_release_paths`.
- **Artists/Genres/Descriptors/Labels list**: list entities, filter by CanShower, filter by `hide_*_with_only_new_releases`, sanitize names.
- **Loose Tracks**: filter by releasetype=loosetrack.
- **Collage + collage name**: get collage releases, yield via `list_release_paths` + ALL_TRACKS.
- **Collages list**: `list_collages()`.
- **Playlist + name**: get playlist, yield cover art + tracks via `list_track_paths`.
- **Playlists list**: `list_playlists()`.

### 6. Mutation operations
- `unlink(p)`: delete track from playlist, or delete playlist cover art.
- `mkdir(p)`: create collage or create playlist.
- `rmdir(p)`: delete collage, remove release from collage, delete playlist, delete release.
- `rename(old, new)`: rename collage or rename playlist.

### 7. File operations (open, read, write, release)
- `open(p, flags)`: handle collage addition (`.rose.{uuid}.toml` with O_CREAT), regular file open (wrap host FH), cover art creation sequence, playlist track addition sequence.
- `read(fh, offset, length)`: check special ops first, then unwrap host FH.
- `write(fh, offset, data)`: check special ops first, then unwrap host FH.
- `release(fh)`: process special ops (add-track-to-playlist via temp file + AudioTags, new-cover-art via temp file), trigger `update_cache_for_releases` if writable handle, then close host FH.
