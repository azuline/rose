# Task 038: Port CLI Playlist Commands (M-12.7)

## Objective
Wire all playlist-related CLI subcommands to rose-core functions, including cover art management.

## Context
Rose is a music library manager being migrated from Python to Rust. Playlist commands let users create, rename, delete, manage track membership, edit in $EDITOR, print as JSON, and manage playlist cover art. Playlists are identified by name. Track arguments use the same UUID/path resolution as track commands.

## Constraints Relevant to This Task
- Playlist names are plain strings.
- `add-track` and `remove-track` take a track argument (UUID or path) — reuse `parse_track_argument` from task 036.
- Playlists support cover art (set/delete), unlike collages.

## What to Implement

### Subcommands (all under `rose playlists`):

#### `rose playlists create <NAME>`
Create a new playlist. Calls `create_playlist(c, name)`.

#### `rose playlists rename <OLD_NAME> <NEW_NAME>`
Rename a playlist. Calls `rename_playlist(c, old_name, new_name)`.

#### `rose playlists delete <PLAYLIST>`
Delete a playlist. Calls `delete_playlist(c, name)`.

#### `rose playlists add-track <PLAYLIST> <TRACK>`
Add a track to a playlist. Resolve track via `parse_track_argument`. Calls `add_track_to_playlist(c, playlist, track_id)`.

#### `rose playlists remove-track <PLAYLIST> <TRACK>`
Remove a track from a playlist. Resolve track via `parse_track_argument`. Calls `remove_track_from_playlist(c, playlist, track_id)`.

#### `rose playlists edit <PLAYLIST>`
Open playlist in $EDITOR for reorder/removal. Calls `edit_playlist_in_editor(c, name)`.

#### `rose playlists print <PLAYLIST>`
Print a playlist as JSON. Calls `dump_playlist(c, name)`.

#### `rose playlists print-all`
Print all playlists as JSON. Calls `dump_all_playlists(c)`.

#### `rose playlists set-cover <PLAYLIST> <COVER_PATH>`
Set a playlist's cover art from a file. Calls `set_playlist_cover_art(c, name, path)`.

#### `rose playlists delete-cover <PLAYLIST>`
Delete a playlist's cover art. Calls `delete_playlist_cover_art(c, name)`.
