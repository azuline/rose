# Task 035: Port CLI Release Commands (M-12.4)

## Objective
Wire all release-related CLI subcommands to rose-core functions, including argument parsing for release identifiers (UUID or path).

## Context
Rose is a music library manager being migrated from Python to Rust. Release commands let users print, edit, toggle flags, manage cover art, and run rules on releases. Release arguments accept either a UUID string or a filesystem path (source dir or VFS path), which is resolved to a release UUID.

## Constraints Relevant to This Task
- Release argument resolution: if the argument is a valid UUID, use it directly. Otherwise, treat it as a path, scan for `.rose.{uuid}.toml` in the directory, and extract the UUID. Error if not found.
- `set-rating` requires either a rating value (1-100) or `--clear`.
- `run-rule` `--yes` flag inverts to `confirm_yes=false` (Python: `confirm_yes=not yes`).
- `create-single` with `--loose-track` sets releasetype to `"loosetrack"` instead of `"single"`.

## What to Implement

### Helper: `parse_release_argument(r: &str) -> Result<String>`
1. If `r` is a valid UUID, return it.
2. Otherwise, resolve as path, scan directory for `.rose.{uuid}.toml`, extract UUID.
3. Error with helpful message listing the 3 accepted formats.

### Helper: `valid_uuid(s: &str) -> bool`

### Subcommands (all under `rose releases`):

#### `rose releases print <RELEASE>`
Print a single release as JSON. Calls `dump_release(c, id)`.

#### `rose releases print-all [MATCHER]`
Print all releases as JSON. Optional matcher string (parsed via `Matcher::parse`). Calls `dump_all_releases(c, matcher)`.

#### `rose releases edit <RELEASE> [--resume <PATH>]`
Edit release metadata in $EDITOR. Calls `edit_release(c, id, resume_file)`.

#### `rose releases toggle-new <RELEASE>`
Toggle a release's "new" flag. Calls `toggle_release_new(c, id)`.

#### `rose releases toggle-favorite <RELEASE>`
Toggle a release's "favorite" flag. Calls `toggle_release_favorite(c, id)`.

#### `rose releases set-rating <RELEASE> [RATING] [--clear]`
Set or clear a release's rating. `--clear` sets to None. Without `--clear`, a rating integer is required.

#### `rose releases delete <RELEASE>`
Delete a release (move to trash). Calls `delete_release(c, id)`.

#### `rose releases set-cover <RELEASE> <COVER_PATH>`
Set a release's cover art from a file. Calls `set_release_cover_art(c, id, path)`.

#### `rose releases delete-cover <RELEASE>`
Delete a release's cover art. Calls `delete_release_cover_art(c, id)`.

#### `rose releases run-rule <RELEASE> [ACTIONS...] [--dry-run] [--yes]`
Run rule actions on all tracks in a release. Parses each action string via `Action::parse`. `--yes` bypasses confirmation (`confirm_yes = !yes`).

#### `rose releases create-single <TRACK_PATH> [--loose-track]`
Create a single release for a track. `--loose-track` → releasetype `"loosetrack"`, otherwise `"single"`.

## API to Produce
