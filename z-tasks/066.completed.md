# Task 066: Rules — Action Types and Pattern Matching Integration Tests (T-8.2)

## Objective
Add Rust integration tests for the full rules pipeline exercising all match types (substring, prefix, suffix, exact, case-insensitive, escaped anchors) and all action types (replace with `;` delimiter, sed, split, add, delete, chained actions).

## Context
Python has 15+ tests covering match-type variations and action-type variations through the full pipeline. The Rust rules module only has unit-level tests for these; no integration tests verify the end-to-end flow.

## Files to Read
- `rose-rs/rose-core/src/rules.rs` — Rust implementation + tests
- `rose-py/rose/rules_test.py` — Python tests: `test_rules_execution_match_*`, `test_action_*`, `test_sed_*`, `test_split_*`, `test_add_*`, `test_delete_*`, `test_chained_action`, `test_preserves_unmatched_multitags`

## What to Implement

Add the following integration tests:

### Match type variations:
1. **`test_pipeline_substring_match`** — `tracktitle:rack` matches "Track 1", replace works.
2. **`test_pipeline_prefix_match`** — `tracktitle:^Track` matches, `tracktitle:^ack` does not.
3. **`test_pipeline_suffix_match`** — `tracktitle:ck 1$` matches.
4. **`test_pipeline_exact_match`** — `tracktitle:^Track 1$` matches, `tracktitle:^Track$` does not.
5. **`test_pipeline_case_insensitive`** — `tracktitle:track 1:i` matches "Track 1".
6. **`test_pipeline_escaped_anchors`** — `tracktitle:\^literal` does not treat `^` as anchor.

### Action type variations:
7. **`test_pipeline_replace_with_semicolon`** — Replace genre with `"Techno;House"` → splits into two genres.
8. **`test_pipeline_sed_action`** — Sed regex on tracktitle (e.g. `s/Track/Song/`).
9. **`test_pipeline_split_action`** — Split a multi-value tag on a delimiter.
10. **`test_pipeline_add_action`** — Add a new genre value.
11. **`test_pipeline_delete_action`** — Delete a matching genre value.
12. **`test_pipeline_delete_no_pattern`** — Delete all values from a multi-value tag.
13. **`test_pipeline_chained_actions`** — Two sequential actions on the same tag.
14. **`test_pipeline_preserves_unmatched`** — Replace only matching value in a multi-value tag, other values preserved.

### Ignore matchers:
15. **`test_pipeline_ignore_matcher`** — Rule with an ignore matcher: matched track that also matches ignore is skipped.
