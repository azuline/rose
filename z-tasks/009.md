# Task 009: Port config.rs (M-5.1)

## Objective
Port the configuration module from Python to Rust, including TOML parsing, validation, defaults, artist alias resolution, path template integration, stored metadata rules, VFS config, and unknown-key detection.

## Context
Rose is a music library manager being migrated from Python to Rust. The config module parses a TOML configuration file and produces a validated `Config` struct that every other module depends on. It integrates with templates (for path template config) and the rule parser (for stored metadata rules).

## Constraints Relevant to This Task
- **Config format can change** — the user will adjust. But maintain the same semantic structure.
- Unknown config keys should produce a warning (not an error), matching Python behavior.
- Use `dirs` crate for XDG directory resolution (replaces Python's `appdirs`).

### `Config::parse(config_path_override: Option<&Path>) -> Result<Config, RoseError>`
Parse from TOML file. Key behaviors:
1. Read file from `config_path_override` or default XDG path.
2. **Required key:** `music_source_dir` (error if missing).
3. **Optional keys with defaults:**
   - `cache_dir` -> XDG cache dir
   - `max_proc` -> `num_cpus / 2` (min 1)
   - `cover_art_stems` -> `["folder", "cover", "art", "front"]`
   - `valid_art_exts` -> `["jpg", "jpeg", "png"]`
   - `write_parent_genres` -> `false`
   - `max_filename_bytes` -> `180`
   - `rename_source_files` -> `false`
   - `ignore_release_directories` -> `[]`
4. **Artist aliases:** Parse `[[artist_aliases]]` array of `{ artist = "...", aliases = ["...", ...] }`. Build both forward and reverse maps.
5. **Stored metadata rules:** Parse `[[stored_metadata_rules]]` array of `{ matcher = "...", actions = ["...", ...], ignore = ["...", ...] }`. Use `Rule::parse`.
6. **Path templates:** Parse `[path_templates.default]` overrides first, then per-view overrides (`[path_templates.source]`, etc.). Use `PathTemplateConfig::with_defaults()` as base.
7. **VFS config:** Parse `[vfs]` section.
8. **Unknown-key detection:** After consuming all known keys, if any keys remain in the parsed TOML, emit `tracing::warn!` for each unrecognized key (using DFS for nested keys).

## Tests to Write
1. **Minimal config:** Only `music_source_dir` + `[vfs] mount_dir` -> all defaults applied correctly.
2. **Full config:** All keys specified -> parsed correctly.
3. **Missing required key:** No `music_source_dir` -> `MissingConfigKeyError`.
4. **Invalid TOML:** Garbage file -> `ConfigDecodeError`.
5. **File not found:** Nonexistent path -> `ConfigNotFoundError`.
6. **Artist aliases:** Forward and reverse maps populated correctly.
7. **Whitelist/blacklist mutual exclusion:** Both specified -> error.
8. **Stored metadata rules:** Valid rules parsed; invalid rule syntax -> error.
9. **Path template overrides:** Default + per-view overrides applied correctly.
10. **Unknown keys warning:** Config with `unknown_key = "value"` produces a warning (test via log capture or similar).
11. **`max_proc` validation:** `max_proc = 0` -> error, `max_proc = 4` -> 4.
12. **`valid_cover_arts`:** With default stems and exts, produces `["folder.jpg", "folder.jpeg", "folder.png", ...]`.
