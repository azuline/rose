# Task 063: Releases — Create Single Release and Rule Matching Tests (T-6.3)

## Objective
Add Rust integration tests for `create_single_release` (extracting a track into a new single/loosetrack release) and `find_releases_matching_rule` (rule matching with optimized and FTS fallback paths).

## Context
Python's `test_extract_single_release` tests the full single-extraction pipeline (directory creation, file copy, tag rewriting, cover art copy, cache update). Python's `test_find_matching_releases` tests 10 different matcher queries. Neither has a Rust equivalent.

## Files to Read
- `rose-rs/rose-core/src/releases.rs` — Rust implementation + tests
- `rose-py/rose/releases_test.py` — Python tests: `test_extract_single_release`, `test_extract_single_release_with_trailing_space`, `test_find_matching_releases`, `test_run_action_on_release`

## What to Implement

Add the following integration tests:

1. **`test_create_single_release`** — Seed a multi-track release with cover art. Call `create_single_release` for one track. Assert:
   - A new directory is created with the expected name (artist - date. title format)
   - The track file is copied as `01. {title}.{ext}`
   - Cover art is copied
   - Audio tags have: tracknumber="1", discnumber="1", releasetype="single", releaseartists set to trackartists
   - Rose IDs are cleared (new IDs assigned)
   - Cache is updated (new release exists)
   - Original release is untouched

2. **`test_create_single_release_trailing_space`** — Set a track title with trailing whitespace. Create single. Assert the directory and filename have trailing space stripped.

3. **`test_find_releases_matching_rule`** — Seed the test database. Test at least 5 matchers:
   - `releasetitle:Release 2` (substring/FTS fallback)
   - `artist:^Techno Man$` (strict artist, optimized path)
   - `genre:^Deep House$` (strict genre, optimized)
   - `label:^Native State$` (strict label, optimized)
   - `descriptor:^Wet$` (strict descriptor, optimized)
   Assert correct release IDs are returned for each.

4. **`test_run_actions_on_release`** — Parse action `tracktitle/replace:Bop`. Run on a seeded release. Assert track titles changed.
