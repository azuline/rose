# Task 007: Port rule_parser.rs (M-3.1)

## Objective
Port the rule parser DSL from Python to Rust, including all parse functions, type definitions, and the escaping protocol. This module is pure parsing logic with zero I/O.

## Context
Rose is a music library manager being migrated from Python to Rust. The rule parser defines a DSL for matching and transforming metadata tags. Rules consist of a matcher (which tags to search, pattern to match) and actions (replace, sed, split, add, delete). This module can run in parallel with audio tag work since it only depends on `common.rs`.

## Constraints Relevant to This Task
- **Regex flavor difference:** Rust `regex` crate uses `$1`/`${name}` for replacement syntax vs Python's `\1`/`\g<name>`. The sed action stores a compiled regex and replacement string — document the syntax change.
- Use `fancy-regex` if lookaround is needed, otherwise stick with `regex`.
- Port all 544 lines of test cases from `rule_parser_test.py`.

## What to Implement

### 1. Create `rose-rs/rose-core/src/rule_parser.rs`

### Tag type system
Define a `Tag` enum (or string-typed constants) for all 31 tag fields:
`tracktitle`, `trackartist[main]`, `trackartist[guest]`, ..., `releaseartist[djmixer]`, `releasetype`, `releasedate`, `originaldate`, `compositiondate`, `catalognumber`, `edition`, `genre`, `secondarygenre`, `descriptor`, `label`, `new`, `favorite`, `rating`.

Define `ExpandableTag` — includes `artist`, `trackartist`, `releaseartist` as aliases that expand to multiple tags.

Define `ALL_TAGS` mapping (expandable -> resolved list), `MODIFIABLE_TAGS`, `SINGLE_VALUE_TAGS`, `RELEASE_TAGS`.

### `Pattern` struct
```rust
pub struct Pattern {
    pub needle: String,
    pub strict_start: bool,  // ^ prefix
    pub strict_end: bool,    // $ suffix
    pub case_insensitive: bool,  // :i flag
}
```
Constructor parses `^`/`$` from needle string. Escaped `\^` and `\$` are literal.

### `Matcher` struct
```rust
pub struct Matcher {
    pub tags: Vec<Tag>,
    pub pattern: Pattern,
}
```
`Matcher::parse(raw: &str) -> Result<Matcher, RoseError>` — parse `tag1,tag2:pattern:flags` syntax.

### Action types
```rust
pub struct ReplaceAction { pub replacement: String }
pub struct SedAction { pub src: Regex, pub dst: String }
pub struct SplitAction { pub delimiter: String }
pub struct AddAction { pub value: String }
pub struct DeleteAction;

pub enum ActionBehavior { Replace(ReplaceAction), Sed(SedAction), Split(SplitAction), Add(AddAction), Delete(DeleteAction) }
```

### `Action` struct
```rust
pub struct Action {
    pub tags: Vec<Tag>,
    pub behavior: ActionBehavior,
    pub pattern: Option<Pattern>,
}
```
`Action::parse(raw: &str, action_number: Option<usize>, matcher: Option<&Matcher>) -> Result<Action, RoseError>`

### `Rule` struct
```rust
pub struct Rule {
    pub matcher: Matcher,
    pub actions: Vec<Action>,
    pub ignore: Vec<Matcher>,
}
```
`Rule::parse(matcher: &str, actions: &[&str], ignore: Option<&[&str]>) -> Result<Rule, RoseError>`

### Escaping protocol
Port `take()` function — reads until unescaped `:` or `/`, handles `::` -> `:` and `//` -> `/` escaping.
Port `escape()` — reverse.
Port `stringify_tags()` — collapses expanded aliases back to shorthand form.

### Display impls
All types should implement `Display` matching the Python `__str__` methods, so rules can be serialized back to their DSL form.

### Error types
`InvalidRuleError` and `RuleSyntaxError` with position-aware error messages showing where in the input parsing failed.

### 2. Update `lib.rs`
Add `pub mod rule_parser;`

## API to Produce
```rust
// rose-core/src/rule_parser.rs
pub enum Tag { TracktTitle, TrackArtistMain, ... }  // or string-typed
pub struct Pattern { pub needle: String, pub strict_start: bool, pub strict_end: bool, pub case_insensitive: bool }
pub struct Matcher { pub tags: Vec<Tag>, pub pattern: Pattern }
pub struct Action { pub tags: Vec<Tag>, pub behavior: ActionBehavior, pub pattern: Option<Pattern> }
pub enum ActionBehavior { Replace(ReplaceAction), Sed(SedAction), Split(SplitAction), Add(AddAction), Delete(DeleteAction) }
pub struct Rule { pub matcher: Matcher, pub actions: Vec<Action>, pub ignore: Vec<Matcher> }
impl Matcher { pub fn parse(raw: &str) -> Result<Matcher, RoseError>; }
impl Action { pub fn parse(raw: &str, action_number: Option<usize>, matcher: Option<&Matcher>) -> Result<Action, RoseError>; }
impl Rule { pub fn parse(matcher: &str, actions: &[&str], ignore: Option<&[&str]>) -> Result<Rule, RoseError>; }
pub fn take(x: &str, until: char) -> (String, usize);
pub fn escape(x: &str) -> String;
pub fn stringify_tags(tags: &[Tag]) -> String;
```
