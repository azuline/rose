# Task 061: Releases — CRUD Integration Tests (T-6.1)

## Objective
Add Rust integration tests for release CRUD operations: delete, toggle new, toggle favorite, set rating, set cover art, and delete cover art.

## Context
The Rust `releases.rs` module has only 5 unit tests (serialization roundtrips + rating validation). All 11 Python integration tests have zero Rust equivalents. This is the most severe test gap in the codebase. This task covers the simpler CRUD operations; the editor flow and `create_single_release` are covered in subsequent tasks.

## Files to Read
- `rose-rs/rose-core/src/releases.rs` — Rust implementation + tests (tests start ~line 1391)
- `rose-py/rose/releases_test.py` — Python tests: `test_delete_release`, `test_toggle_release_new`, `test_toggle_release_favorite`, `test_set_release_cover_art`, `test_remove_release_cover_art`

## What to Implement

Add the following integration tests to `rose-rs/rose-core/src/releases.rs`. These require the seeded test database + test audio files (use the same fixture pattern as `cache.rs` tests):

1. **`test_delete_release`** — Seed a release. Call `delete_release`. Assert the source directory is gone (or trashed). Assert the release no longer exists in the cache DB.

2. **`test_toggle_release_new`** — Seed a release (default `new=true`). Toggle new → assert `new=false` in both sidecar TOML and cache DB. Toggle again → assert `new=true`.

3. **`test_toggle_release_favorite`** — Seed a release (default `favorite=false`). Toggle → assert `favorite=true` in sidecar + DB. Toggle back → assert `favorite=false`.

4. **`test_set_release_rating`** — Seed a release. Set rating to 85. Assert rating=85 in sidecar + DB. Set to None (clear). Assert rating is None in sidecar + DB.

5. **`test_set_release_cover_art`** — Seed a release with existing cover art files. Create a new image file. Call `set_release_cover_art`. Assert old cover files deleted, new cover exists, DB `cover_image_path` updated.

6. **`test_delete_release_cover_art`** — Seed a release with cover art. Delete cover art. Assert file gone, DB `cover_image_path` is NULL.

7. **`test_set_release_rating_invalid`** — Attempt to set rating to 0 and 101. Assert both return errors.

7 new test functions.
